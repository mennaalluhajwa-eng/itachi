#  Uchiha Itachi — Interactive Canvas Web Experience

An interactive, dark-themed web experience featuring Uchiha Itachi with custom HTML5 Canvas animations and dynamic background audio integration.

 **Live Demo:** [Visit Live Site](https://itachi-master-mu.vercel.app/)
---

##  Features & Enhancements

- **HTML5 Canvas Visuals:** Mouse-tracking Sharingan, Amaterasu black flames effect, particle systems, and lightning storms.
- **Dynamic Audio Integration:** Integrated background theme audio with a custom fallback mechanism handling modern browser **Autoplay restrictions**.
- **Responsive & Optimized:** Clean UI structure, smooth FPS animations, and fully deployed on Vercel.

---

##  Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Graphics:** HTML5 Canvas API
- **Deployment:** Vercel
